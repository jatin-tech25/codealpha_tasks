## 🚀 Projects Completed

### 1. 🎮 Hangman Game

A simple **text-based Hangman game** developed in Python.

**Features:**
- Selects a word from a predefined list.
- Player guesses the word one letter at a time.
- Allows a maximum of **6 incorrect guesses**.
- Runs completely in the console.

**Concepts Used:**
- `random`
- Lists
- Strings
- `while` loop
- `if-else`
- User input/output

The CodeAlpha task specifically defines Hangman as a console-based game using a small predefined word list and six incorrect guesses. fileciteturn0file0L28-L34

### 2. 📈 Stock Portfolio Tracker

A Python-based **Stock Portfolio Tracker** that calculates the total investment value using stock quantities and predefined stock prices.

**Features:**
- Takes stock names from the user.
- Takes the quantity of each stock.
- Uses a predefined stock-price dictionary.
- Calculates the total investment value.
- Can optionally save the result to a text or CSV file.

**Concepts Used:**
- Dictionaries
- User input/output
- Basic arithmetic
- File handling

The CodeAlpha task specifies manually defined stock prices and user-entered stock names and quantities. fileciteturn0file0L37-L45

### 3. 🤖 Basic Chatbot

A simple **rule-based chatbot** developed using Python.

**Features:**
- Accepts user messages.
- Responds to predefined inputs such as:
  - `hello`
  - `how are you`
  - `bye`
- Uses predefined responses.
- Continues the conversation using a loop.

**Concepts Used:**
- `if-elif`
- Functions
- Loops
- User input/output

The CodeAlpha task describes this as a basic rule-based chatbot with predefined user inputs and responses. fileciteturn0file0L53-L58
